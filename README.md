# QUANTUM NEXUS v2.8
### The Antigravity Multidimensional Environment

**QUANTUM NEXUS** is a state-of-the-art cyber-luminescent web application built to showcase the full depth of Antigravity: **Seeable Visuals**, **Auditive Procedural Sound**, **Tactile Physics**, and **Deep Cognitive Intelligence**.

---

## 🌌 Core Subsystems & Features

### 1. Visual & Kinetic Simulation
- **60+ FPS Quantum Particle Engine**: 1,000+ interactive particles with dynamic gravitational attraction, repulsion shields, and bipolar vortex dynamics.
- **Hold-to-Charge "Mega Attraction Well"**: Touch/click and hold to dynamically expand the gravitational suction radius up to 600px+ with 7x suction power, swirling violet spokes, and implosion release shockwaves.
- **Singularity Lens**: Procedural gravitational lensing with accretion disk rotation.
- **Neural Lattice**: Live synaptic firing network graph.
- **FFT Audio Spectrum Radar**: Real-time frequency spectrum analysis and circular radar audio visualization.

### 2. Procedural Web Audio Synthesis (Zero External Dependencies)
- **Polyphonic Synthesizer**: Procedural Web Audio API oscillator bank with ADSR envelopes, low-pass resonant filters, delay lines, and stereo panners.
- **5 Cybernetic Scales**: *Cyber Lydian*, *Neo-Tokyo Insen*, *Major Pentatonic*, *Deep Void Minor*, *High Celestial*.
- **Generative Soundscape**: 10 Hz Alpha-wave binaural beat generator and evolving harmonic drone progressions.
- **16-Step Sound Matrix**: Interactive polyphonic sequencer grid with BPM tempo adjustment.
- **Continuous XY Theremin**: Dual-axis touch ribbon for continuous pitch glide (X-axis) and filter resonance (Y-axis).

### 3. Cognitive Depth & Swarm Intelligence
- **Agent Swarm Matrix**: 4-agent autonomous swarm simulation (*Antigravity Prime*, *Neural Weaver*, *Veritas Guardian*, *Aether Vision*) with live telemetry and state transitions.
- **Tree-of-Thought Engine**: Branching decision tree with real-time heuristic scoring.
- **Algorithmic Code Weaver**: Procedural generation of Lissajous manifolds, Lorenz attractors, and quantum wavepackets.

### 4. Smartphone & Desktop Optimized Layout
- **Pure Icon Command Header**: High-density icon controls (`[ ⏻ ]` Power, `[ 👁️ ]` Panels, `[ ● ]` Sync, `[ 🔊 ]` Audio) with zero text overflow.
- **7-Tool Mobile Bottom Dock**: Direct sliding-drawer access to all 7 tools (`🧲 Force`, `♪ Matrix`, `≋ Theremin`, `Ω Swarm`, `🌿 Reason`, `💻 Code`, `📊 FFT`) without obstructing the full-screen particle canvas.
- **Desktop Zen Mode**: Master panel toggle (`P: ON/OFF` or key <kbd>H</kbd>/<kbd>Tab</kbd>) for distraction-free immersion.

## 🕹️ Controls & Shortcuts

| Action | Key / Gesture | Description |
| :--- | :--- | :--- |
| **Attract Particles** | <kbd>A</kbd> / Touch & Hold | Accelerates particles toward cursor / Charges Mega Attraction Well |

| **Toggle Panels** | <kbd>H</kbd> or <kbd>Tab</kbd> / `[ 👁️ ]` | Shows/hides HUD panels for full-screen zen mode |
| **Toggle Audio** | <kbd>M</kbd> / `[ 🔊 ]` | Mutes/unmutes master audio engine |

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve locally:

```bash
# Python 3
python -m http.server 8080

# Or Node.js
npx serve .
```

Open `http://localhost:8080` in your browser.
